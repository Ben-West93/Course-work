Title: LLM Application Developer
Company: Lumen Fieldworks
Location: Remote (US or Canada)

Lumen Fieldworks makes software for agricultural field inspectors. Inspectors photograph crops, write notes and need quick answers from long regulation manuals while they're out in the field, often with poor connectivity.

## What you'll build

- An assistant that answers inspector questions from regulation manuals, with citations to the exact section
- Offline-capable inference using small local models through Ollama
- Internal tools in Streamlit for the compliance team to review answers
- Prompt templates and guardrails that keep answers inside the source documents

## You should have

- Python experience and at least one shipped project that uses an LLM
- Experience with retrieval-augmented generation and a vector store (ChromaDB, FAISS or similar)
- Prompt engineering for grounded answers and citation
- Familiarity with running local models (Ollama, llama.cpp) and their trade-offs
- Ability to write clear documentation for non-technical users

## Helpful but not required

- LangChain or LlamaIndex
- Streamlit or Gradio
- TypeScript for our inspector mobile app
- Experience with evaluation of LLM answers

## Compensation

$100,000 to $120,000 USD, fully remote, home office stipend.
