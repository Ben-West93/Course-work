Title: Junior Python Developer
Company: Tidewater Energy Cooperative
Location: Norfolk, VA (on site)

Tidewater Energy Cooperative supplies power to 60,000 rural members. Our small software team builds the internal tools for outage reporting, meter data and field crew scheduling.

## What the job involves

- Build and maintain internal REST APIs in Python
- Write data imports for smart-meter readings using pandas
- Add tests with pytest and keep our test coverage above 80 percent
- Fix bugs reported by the operations team and document the fixes

## What you need

- Python fundamentals: functions, classes, error handling, virtual environments
- Some experience building or consuming REST APIs
- Basic SQL and an ORM such as SQLAlchemy
- Unit testing with pytest
- Comfortable working on the Linux command line

## Good to have

- FastAPI or Flask
- Experience with time-series data
- Interest in utilities or energy

## Pay and schedule

$72,000 to $85,000, Monday to Friday, no on-call in the first year.
