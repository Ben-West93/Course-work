Title: Full Stack Engineer (Early Career)
Company: Pebble Payments
Location: Denver, CO (hybrid)

## What you'll do

- Build features across our React front end and Python and Node.js services
- Design PostgreSQL tables and write migrations
- Implement secure login flows with OAuth 2.0 and JWT
- Write tests for both front end (Jest) and back end (pytest)
- Join design reviews and help shape the roadmap

## Requirements

- Experience with React and TypeScript
- Backend experience in Python or Node.js
- PostgreSQL or another relational database
- Understanding of web security basics: authentication, authorization, OWASP Top 10
- Git and code review

## Nice to have

- Payments or fintech experience
- Docker and CI/CD
- Experience with Stripe or a similar payments API
