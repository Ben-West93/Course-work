Title: Junior Platform Engineer, AI Infrastructure
Company: Quillstone Legal Tech
Location: New York, NY (hybrid)

Quillstone builds contract review tools for law firms. Our platform team runs the infrastructure behind the model-serving and document-processing services.

## Responsibilities

- Maintain Kubernetes clusters that run our model-serving and document pipelines
- Write and review Terraform for cloud infrastructure
- Build GitHub Actions workflows for testing, image builds and deployments
- Improve observability with Prometheus, Grafana and structured logging
- Help product teams containerize new services with Docker

## Required qualifications

- Experience with Docker and container image best practices (multi-stage builds, small images)
- Working knowledge of Kubernetes: deployments, services, config maps, secrets
- Scripting in Python or Bash
- CI/CD pipelines, preferably GitHub Actions
- Linux fundamentals and networking basics (DNS, TLS, load balancing)

## Preferred qualifications

- Terraform or another infrastructure-as-code tool
- Experience serving ML models or GPUs in production
- Security awareness: secrets management, least privilege

## Compensation

$115,000 to $135,000, plus equity.
