Title: Backend Developer (Python)
Company: Cobalt Freight
Location: Chicago, IL (hybrid, 2 days in office)

Cobalt Freight runs a booking and tracking platform for regional trucking companies. Around 4,000 carriers use it daily to accept loads, report delivery status and get paid.

## The role

You'll join the platform team that owns the booking API and the carrier payment service. Most of the work is in Python services backed by PostgreSQL, deployed to AWS.

## Responsibilities

- Design and build REST endpoints for load booking, tracking events and invoicing
- Write efficient SQL and tune slow queries on tables with tens of millions of rows
- Add unit and integration tests with pytest; keep CI green
- Take part in an on-call rotation once you're settled in (about one week in six)

## Must have

- 2+ years building backend services in Python (Django or FastAPI)
- Strong SQL skills and experience with PostgreSQL in production
- Experience with an ORM such as SQLAlchemy or the Django ORM
- Docker for local development and deployment
- Familiarity with AWS (ECS, RDS, S3)

## Preferred

- Redis for caching or job queues
- Message queues such as SQS or RabbitMQ
- Experience with payments or invoicing systems

## Compensation

$105,000 to $125,000 plus annual bonus.
