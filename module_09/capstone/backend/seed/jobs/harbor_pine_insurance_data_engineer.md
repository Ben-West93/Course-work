Title: Associate Data Engineer
Company: Harbor & Pine Insurance
Location: Hartford, CT (hybrid)

Harbor & Pine is a mid-size home and auto insurer. The data platform team builds the pipelines that feed pricing, claims analytics and regulatory reporting.

## Day to day

- Build and schedule batch pipelines in Apache Airflow
- Model data in dbt and keep tests and documentation up to date
- Load data from policy and claims systems into Snowflake
- Write Python scripts for data quality checks and alerting
- Work with analysts to turn reporting requests into reliable tables

## Requirements

- Strong SQL, including window functions and CTEs
- Python for data processing and scripting
- Experience with at least one orchestration tool (Airflow, Prefect or Dagster)
- Understanding of data warehousing concepts: star schemas, slowly changing dimensions
- Version control with Git and CI/CD for data pipelines

## Nice to have

- dbt
- Snowflake or BigQuery
- Insurance or financial services background

## Salary

$90,000 to $108,000, pension plus 401(k) match.
