Introduction to Python

Python is a high-level, interpreted programming language created by Guido van Rossum and first released in 1991. It emphasizes code readability and simplicity, which makes it a popular choice for beginners and professionals alike.

Python supports multiple programming paradigms, including procedural, object-oriented, and functional programming. Its design philosophy is captured in "The Zen of Python", which can be read by running `import this` in any Python interpreter.

Python uses dynamic typing, meaning you don't need to declare variable types explicitly. Variables take the type of the value assigned to them and can change type throughout the program.

Python Functions

Functions in Python are defined using the `def` keyword. They can accept positional arguments, keyword arguments, default values, and variable-length argument lists using *args and **kwargs.

A function that takes no arguments and returns a value:
    def greet():
        return "Hello, world!"

A function with parameters and a default value:
    def greet(name="stranger"):
        return f"Hello, {name}!"

Python List Comprehensions

List comprehensions provide a concise way to create lists. The syntax is:
    [expression for item in iterable if condition]

For example, to create a list of even numbers from 1 to 20:
    evens = [n for n in range(1, 21) if n % 2 == 0]

List comprehensions are generally faster than equivalent for-loops because they are optimized at the interpreter level.

Python Dictionaries

Dictionaries store key-value pairs. Keys must be hashable (strings, numbers, tuples) and unique within a dictionary. Values can be any Python object.

    person = {"name": "Alice", "age": 30, "city": "Melbourne"}
    print(person["name"])   # Alice

Iterating over a dictionary:
    for key, value in person.items():
        print(f"{key}: {value}")

Python Error Handling

Python uses try/except blocks to handle exceptions. The `finally` block runs regardless of whether an exception occurred, making it useful for cleanup.

    try:
        result = 10 / 0
    except ZeroDivisionError as e:
        print(f"Error: {e}")
    finally:
        print("Done")

You can define custom exceptions by subclassing the built-in Exception class. Raising and catching specific exception types makes code easier to debug and maintain.
